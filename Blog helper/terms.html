1. 약관의 적용

이 약관은 「블로그 글 작성 도우미」(이하 “앱”)를 설치하거나 실행하는 모든 이용자에게 적용됩니다. 앱을 사용하면 이 약관에 동의한 것으로 봅니다.

2. 서비스

앱은 이용자가 고른 사진과 공개된 네이버 블로그 글의 문체를 바탕으로 블로그 초안을 만드는 도구입니다. 회원 가입은 없습니다. 운영자 서버는 없으며, 설정과 API 키는 이용자 기기에만 저장됩니다.

글 생성에는 이용자가 직접 넣은 Google Gemini API 키가 필요합니다. 사진, 현장 힌트, 학습에 쓰인 글은 그 키로 Google 서버에 전달됩니다. 네이버 계정 비밀번호는 받지 않고, 이용자가 적은 블로그 주소의 공개 RSS만 읽습니다.

3. 초안의 성격

만들어진 글은 초안입니다. 사실, 상호, 치수, 후기가 맞는지 확인하고 이용자가 고친 뒤에 블로그에 올립니다. 생성된 문장으로 생긴 명예훼손, 저작권, 광고 표시 문제는 게시한 이용자에게 있습니다.

사진과 원본 글의 권리는 이용자 또는 원래 권리자에게 있습니다. 앱은 그 자료를 운영자가 보관하거나 판매하지 않습니다.

4. API 키와 외부 서비스

Gemini API 사용료는 이용자의 Google 계정에 청구될 수 있으며, 운영자가 그 요금을 대신 받지 않습니다. API 키는 다른 사람에게 보여 주지 않아야 합니다. Gemini, 네이버 RSS, Google AdMob의 데이터 처리는 각 사업자의 정책을 따릅니다.

5. 광고와 결제

앱은 Google AdMob으로 배너·전면 광고를 표시할 수 있습니다. 광고 상품은 개발자가 판매하거나 보증하지 않습니다. 앱 이용 자체에 운영자에게 내는 구독료는 없습니다. 유료 기능이 추가되면 결제는 Google Play를 통합니다.

6. 이용자의 책임

권리 없는 사진이나 글을 학습·생성에 넣지 않습니다. 앱을 변조하거나 광고·API 시스템에 피해를 주는 행위는 허용되지 않습니다. 갤러리의 Pictures/블로그글작성도우미 폴더에 저장된 사진은 앱을 지운 뒤에도 남을 수 있습니다.

7. 책임의 한계

생성 결과의 정확성, API 장애, 광고 페이지 이용으로 생긴 손해에 대해 운영자는 고의 또는 중대한 과실이 없는 한, 법이 허용하는 범위에서 책임을 집니다.

8. 변경과 준거법

약관이 바뀌면 이 페이지의 시행일을 고칩니다. 이 약관은 대한민국 법령을 따르며, 이용자 거주국의 강행 규정에 따른 권리는 유지됩니다.
